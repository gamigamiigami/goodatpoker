# RANGE ROOM

ポーカー初心者が、参加基準を覚え、相手のレンジを読んで判断するための日本語PWAです。ブラウザ内で動き、アカウント・有料API・追加パッケージは不要です。

## 教材の基準

プリフロップの中心資料は[ヨコサワポーカーチャンネル「ハンドランキングの最新版」](https://www.youtube.com/watch?v=NDouTGvor-k)（2025年12月6日公開）です。公式動画のトーナメント用チャート（2:43頃）とアンティなし用チャート（27:24頃）の色分けを、アプリ内で独自の表に再構成しています。公式アプリではありません。

- 普段遊ぶキャッシュゲーム（アンティなし・100BB）を最初の特訓と表の初期表示にしています。アンティありの教材にも切り替えられます。
- 「ヨコサワ表」でアンティの有無、後ろの人数、ハンドを選ぶと、色と基本行動を確認できます。
- 全員フォールドからの参加、通常2〜3BBの初回レイズへの応答、BBの例外を扱います。後ろに1人のSBファーストイン、特殊なベット額、3ベット以降の自動判定は対象外です。
- 教材問題はそれぞれ人数とアンティ条件を表示します。基本のレイズ額は2.5BBです。模擬対戦はアンティなし・100BBで、通常の参加と初回応答に最新版を使います。
- 表は入門用の基準です。勝率や行動頻度を計算した結果ではありません。K9sのBTNレイズは「K9s＝緑」「アンティなしのBTN＝白以上」を対応させて判断します。理由となる位置の利点も説明しますが、その説明だけで境界の期待値は計算できません。
- フロップ以降の相手レンジ、ベット頻度、模擬対戦の特殊局面は本アプリの仮定です。教材画面で公式表の範囲と分けて表示します。計算練習で与えた勝率は実カードに対するソルバー解析ではありません。

## 機能

- ホームは「ヨコサワ表を開く」「初心者向け10問を解く」の2つを主操作にし、コース・模擬対戦・設定は折りたたんでいます。
- 問題画面は、自分のポジション・手札・アンティ条件・周りのアクションを先に表示します。回答後は「最初の候補 → 行動後に残る候補 → そう言える理由 → 今回の判断」の順で、レンジの変化を初心者向けに説明します。
- 問題・模擬対戦の途中でも、現在の状態を残したままヨコサワ表を重ねて開けます。練習中のハンドは表の中で白枠表示します。
- 30問・6コース。ホームからは10問を続けて解け、各テーマのコースでは最大5問ずつ練習できます。最初はアンティなしの参加基準とBBの読み方です。
- 「ヨコサワ表」で選んだアンティ・人数・場面のまま、手札を変えて10問ずつ反復できます。判断後に色と下限を表示します。
- 自由練習5レベル、ボード集中練習、3段階のヒント、誤答の振り返り。ヒントなしの正解で習得とし、苦手を復習できます。
- 自分の席と手札は卓の手前に固定し、他の席は位置の順序を保って配置します。模擬対戦は4〜8人に対応します。
- 模擬対戦の相手は簡易戦略です。ポストフロップの勝率表示は仮定した相手レンジへの160回の試行で、実際の相手の秘密の手札は使いません。
- 固定問題の回答履歴は直近500件、表の10問反復は累計回答・正解・完了セット数を、このブラウザのlocalStorageに保存します。ブラウザのデータを消すと記録も消えます。

## 起動と検証

既存のNode.jsで `node serve.mjs` を実行し、表示されたローカルURLを開きます。サーバーはPC内の `127.0.0.1` にだけ接続します。PCへのインストールや設定変更は不要です。公開用ファイルは `dist/` のみです。

- `node verify-training.mjs`：コース、保存、復習、表示、最新版の判断境界を検証。
- `node verify.mjs`：役判定、4〜8人の750ハンド、チップ保存、カード重複、秘密情報不使用を検証。

PWAのiPhone実機でのホーム画面追加とオフライン動作は、実機での確認が必要です。

## GitHub Pages

`.github/workflows/pages.yml` は `main` への更新時に検証を実行し、`dist/` を GitHub Pages に公開します。リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」に設定します。公開されるのは `dist/` 内の静的アプリだけで、ローカルのNode.jsサーバーやPC側の設定は使いません。
